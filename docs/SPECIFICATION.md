# Room Planner — 仕様書 v0.2 / implementation slice 0.1

## 目標
建築初心者が住宅の2D間取りを作成し、2D・3Dから空間を確認できるGitHub Pages上のWebアプリ。
ChatGPT等が公開スキーマに従ってJSON生成・更新できることを重視する。

## アーキテクチャ不変条件
1. 全寸法はメートル。表示は㎡・帖（換算基準1帖=1.62㎡、設定可能とする）。
2. `Project` が唯一の正。2D・3Dは同一データから導出し、別の間取り状態を持たない。
3. 壁は共有できる頂点グラフ、部屋は向き付き壁ループで管理する。
4. 開口部は `wallId + offset` に固定し、はみ出し・重複を検証する。
5. GitHubリポジトリはリモートの正式保存先。IndexedDBは作業中の一時保存。
6. 公開GitHub Pagesに秘密情報・個人間取りJSON・PATを埋め込まない。
7. GitHub保存は明示操作。競合時は上書きせず再取得・手動調整。
8. PC・スマホの両方で操作しやすい表示にする。

## 完成版で必要な機能
- 壁・部屋のマウス/タッチ操作、数値寸法、グリッド吸着、Undo/Redo
- ㎡、帖、室内寸法、壁長、通路幅、専有面積と内法面積の区別
- 開き戸/引き戸/折れ戸/掃き出し窓/腰高窓/FIX窓と位置・開閉方向
- パラメトリック家具/GLB読み込み/設備/複数階・階段
- 3D俯瞰・人間目線、壁・家具・閉扉非貫通、階段と床の衝突、スマホ移動UI
- 家事/育児/帰宅動線の可視化・距離計算
- 画像の下敷き、スケール合わせ、JSON入出力、差分・履歴

## 初期実装に含める範囲
- React + TypeScript + Three.js + ViteでのGitHub Pages動作
- 壁グラフ・部屋ループ・開口部・家具のモデルと基本的なバリデーション
- 2Dでの矩形部屋追加・頂点編集と㎡/帖表示
- 3Dでの俯瞰表示（プレビュー）、ドア・窓穴の簡易可視化
- JSON入出力、IndexedDBの一時保存、GitHub REST APIの手動同期
- JSON Schemaとユニットテスト

## 初期実装に未対応
- 一人称歩行と物理衝突、3Dドア開閉の実動作、壁の部分共有（T字接続）
- 複数階編集UI、建築法規、耐震解析、任意形状家具、画像からの自動トレース
- GitHub OAuth認証（サーバーレスの都合でトークンは揮発メモリのみ）
- 設計変更の自動マージ

## 品質ゲート
スキーマ違反、閉じない部屋、存在しない壁参照、開口のはみ出し・重複を検知。
エラーがあるプロジェクトはGitHub保存をブロックする。追って交差壁、部屋重複、家具衝突、歩行経路などを検証。
